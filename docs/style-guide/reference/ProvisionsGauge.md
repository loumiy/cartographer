# Provisions gauge

The voyage clock: remaining days of stores as an `ink` bar, with a `vermilion` dashed mark at the point of no return and a muted mark at halfway.

- The figure is always days, never a percentage.
- When remaining days reach the point of no return, the caption turns into the warning and the voyage pauses.
- Pairs with the same gauge style for hull condition.
- Reference drawing; not yet a coded component.
