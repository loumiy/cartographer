# Chart symbols

The fixed vocabulary of marks drawn on the chart; each symbol differs by shape as well as ink so it reads without colour.

- Draw at 1.5px `ink` strokes unless the symbol is a signal (`vermilion` hazards, `gilt` value, `verdigris` objectives).
- Symbols never get labels in boxes; place names are italic text along the coast (see Chart conventions).
- Minimum hit area on the chart: 32×32px around each symbol.
- This preview is a reference drawing, not yet a coded component.
