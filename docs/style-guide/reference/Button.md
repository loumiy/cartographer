# Button

Verb-first actions in the interface: one primary (`ink` fill, `vellum` text) per decision, secondaries outlined in `ink`, risky choices outlined in `vermilion`.

- Label is a verb phrase in sentence case that says what happens ("Turn for home", not "OK").
- `radius-sm`, `label` type style, `space-2` × `space-4` padding.
- Risky buttons state their cost nearby in a `caption` ("Sickness more likely").
- Disabled buttons use `ink-muted` and should explain why in a tooltip.
- Reference drawing; not yet a coded component.
